# Глоссарий Linux

Определения здесь намеренно короткие. Ссылка «см.» ведёт к заметке с моделью и примерами.

## Система и запуск

| Термин | Простое определение |
| --- | --- |
| Linux | Ядро операционной системы; в разговоре — система/дистрибутив на его основе. |
| Kernel, ядро | Привилегированная часть системы, управляющая CPU, памятью, устройствами, процессами и сетью. |
| User space | Область работы обычных программ вне ядра. |
| Дистрибутив | Ядро, программы, пакетный менеджер, настройки и политика обновлений, собранные как система. |
| Firmware | Низкоуровневое ПО устройства; UEFI/BIOS начинает загрузку компьютера. |
| Bootloader | Загрузчик, который выбирает и загружает kernel/initramfs, например GRUB. |
| initramfs | Временная минимальная файловая система, помогающая kernel открыть настоящий root. |
| PID 1 | Первый процесс в PID namespace; на хосте часто systemd. |
| systemd | Распространённый init и service manager. |
| Unit | Объект конфигурации systemd: service, socket, timer, mount и др. |

См. [[01 — Ориентация в Linux]], [[13 — Загрузка Linux и ядро]].

## Терминал и shell

| Термин | Простое определение |
| --- | --- |
| Terminal emulator | Графическое/текстовое приложение, соединяющее клавиатуру и экран с TTY. |
| TTY | Терминальный интерфейс ядра; историческое название от teletype. |
| Shell | Программа, читающая команды и запускающая другие программы: Bash, Zsh, Fish. |
| Bash | GNU Bourne Again Shell, распространённая командная оболочка. |
| Builtin | Команда, выполняемая самим shell, например `cd`. |
| Argument | Отдельная строка, переданная программе при запуске. |
| Option | Аргумент, который по соглашению меняет режим программы, часто начинается с `-`. |
| Quoting | Правила кавычек, управляющие подстановками и границами аргументов. |
| Globbing | Раскрытие шаблонов имён (`*.log`) самим shell. |
| Environment | Набор строковых переменных, передаваемых дочернему процессу. |
| PATH | Переменная со списком каталогов поиска команд. |
| Exit code | Число, возвращаемое завершившимся процессом; 0 обычно означает успех. |
| stdin/stdout/stderr | Стандартный ввод, обычный вывод и поток ошибок. |
| Pipe | Канал, соединяющий stdout одной команды со stdin другой. |
| Redirection | Настройка потоков через `<`, `>`, `2>` и другие операторы shell. |
| EOF | Состояние «данных больше нет» при чтении потока. |

См. [[02 — Терминал и базовые команды]], [[09 — Bash подробнее]], [[11 — Окружение и конфигурация shell]].

## Файлы и хранение

| Термин | Простое определение |
| --- | --- |
| Root `/` | Начало единого дерева путей Linux. Не путать с пользователем root и каталогом `/root`. |
| Path | Последовательность компонентов, указывающая на объект в дереве. |
| Absolute path | Путь от `/`, не зависящий от текущего каталога. |
| Relative path | Путь от текущего рабочего каталога процесса. |
| Inode | Метаданные объекта файловой системы и ссылки на его данные; имя хранится в каталоге. |
| Hard link | Ещё одно имя того же inode. |
| Symbolic link | Отдельный объект, содержащий путь к цели. |
| File descriptor | Маленькое число, которым процесс обозначает открытый файл, сокет или pipe. |
| Filesystem | Формат/логика хранения файлов и каталогов: ext4, XFS, Btrfs и др. |
| Block device | Устройство с блочным доступом, например диск или раздел. |
| Partition | Выделенный диапазон блоков диска. |
| Mount | Подключение файловой системы к каталогу дерева `/`. |
| Mount point | Каталог, в котором становится видна смонтированная ФС. |
| Bind mount | Отображение существующего дерева каталогов в ещё одной точке. |
| UUID | Устойчивый идентификатор ФС/устройства, удобный для `fstab`. |
| tmpfs | Файловая система в памяти, способная использовать swap; непостоянная. |
| Sparse file | Файл с логическим размером больше реально выделенных блоков. |
| inode exhaustion | Состояние, когда закончились inode, хотя свободные байты ещё есть. |

См. [[03 — Файловая система]], [[08 — Сеть, диски и практика]].

## Пользователи и безопасность

| Термин | Простое определение |
| --- | --- |
| root | Пользователь с UID 0 и широкими полномочиями. |
| UID/GID | Числовые идентификаторы пользователя и группы. |
| Effective UID/GID | Идентификаторы, используемые для многих проверок доступа процесса. |
| Supplementary groups | Дополнительные группы процесса. |
| `rwx` | Чтение, запись, выполнение/проход для owner, group, others. |
| Owner | UID-владелец объекта. |
| Group | Основная группа объекта, используемая при проверке group bits. |
| umask | Маска прав, которые убираются при создании файла/каталога. |
| ACL | Дополнительные записи прав сверх owner/group/others. |
| setuid/setgid | Специальные биты с разной семантикой для файлов и каталогов. |
| Sticky bit | На общем каталоге ограничивает удаление/переименование чужих записей. |
| sudo | Выполнение команды с credentials другого пользователя по политике. |
| Capability | Отдельное kernel-полномочие, выделенное из традиционных прав root. |
| SELinux/AppArmor | LSM-механизмы обязательного контроля доступа поверх обычных прав. |

См. [[04 — Пользователи и права]].

## Процессы и ресурсы

| Термин | Простое определение |
| --- | --- |
| Program | Файл с кодом/инструкциями. |
| Process | Запущенный экземпляр программы с PID и ресурсами. |
| Thread | Планируемый поток выполнения внутри процесса; разделяет его память. |
| PID/PPID | ID процесса и ID родительского процесса. |
| fork | Создание дочернего процесса на основе вызывающего. |
| exec | Замена программы текущего процесса новой. |
| Signal | Асинхронное уведомление процессу, например TERM, INT, KILL. |
| Zombie | Завершившийся процесс, статус которого ещё не забрал родитель. |
| Orphan | Процесс, чей родитель завершился; его принимает init/subreaper. |
| RSS | Часть страниц процесса, находящихся в RAM; включает shared pages. |
| VSZ | Размер виртуального адресного пространства, не равный расходу RAM. |
| Swap | Дисковое пространство для вытесненных страниц памяти. |
| Load average | Среднее число runnable-задач и задач в непрерываемом ожидании. |
| OOM killer | Механизм kernel, выбирающий процесс для завершения при критическом дефиците памяти. |
| Nice | Параметр относительного CPU-приоритета для обычной политики планирования. |

См. [[05 — Процессы и сигналы]], [[12 — Память и ресурсы]].

## Сеть

| Термин | Простое определение |
| --- | --- |
| Interface | Сетевой интерфейс: физический или виртуальный. |
| IP address | Адрес интерфейса/узла на сетевом уровне. |
| CIDR prefix | Число бит сетевой части адреса, например `/24`. |
| Route | Правило выбора пути и интерфейса для пакета. |
| Default route | Маршрут, используемый, когда нет более точного. |
| DNS | Система сопоставления доменных имён с записями, включая адреса. |
| Port | Число, помогающее доставить TCP/UDP-трафик конкретному приложению. |
| Socket | Kernel-объект конечной точки обмена данными. |
| Listen | Состояние серверного TCP-сокета, ожидающего соединения. |
| Loopback | Локальный интерфейс; `127.0.0.1`/`::1` не выходят в сеть. |
| Bind address | Локальный адрес, на котором приложение принимает соединения. |
| Firewall | Набор правил фильтрации сетевого трафика. |
| NAT | Изменение сетевых адресов/портов при прохождении трафика. |
| SSH | Протокол защищённого удалённого доступа и выполнения команд. |
| TLS | Протокол шифрования и аутентификации транспорта, используемый HTTPS. |

См. [[08 — Сеть, диски и практика]].

## Как пользоваться глоссарием

Не зубрите таблицу. Когда термин встретился в команде или ошибке, найдите определение, вернитесь в основную заметку и свяжите его с наблюдаемым объектом. Например: увидели PID → найдите `/proc/PID` → посмотрите credentials и FD → сопоставьте их с правами и файловой системой.

Вернуться: [[Linux MOC]].
